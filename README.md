## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Deploy the project folder to Vercel. The build command is:

```bash
npm run build
```

The output directory is:

```bash
dist
```

## Notes

The contact form currently routes users toward WhatsApp. For production CRM/email delivery, connect the form to a backend service, Formspree, Resend, EmailJS, or a CRM endpoint.
